Modes graphiques de Fil

Sept ambiances pour l'écran principal, chacune en clair et en sombre. La maquette ne lit que les jetons du mode choisi : ce qu'on voit ici est ce que changerait un Theme dans Sources/Fil/Design/.

Jetons

Chaque pastille : à gauche la valeur claire, à droite la sombre. success, progress et selection sont nouveaux ; dans Défaut ils reprennent ce que font les vues aujourd'hui (accentInk, accentWash).

Contrastes WCAG

Calculés ici, dans la page, par la même formule que contrastes.py (luminance relative sRGB). Seuil 4,5 pour le texte (1.4.3 AA), 3 pour les éléments graphiques (1.4.11). Les cases en rouge échouent.
